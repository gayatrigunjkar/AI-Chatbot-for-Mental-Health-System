About the Project

The Mental Health Chatbot System is a web-based application designed to support users in managing their mental well-being. This project provides a safe and simple platform where users can interact with a chatbot, receive emotional support, and access relaxing music for peace, study, and meditation.

The system allows users to create an account, log in securely, and communicate with the chatbot. The chatbot responds using predefined intents stored in a JSON file, helping users with basic mental health guidance and positive conversations.

One of the key features of this project is the automatic email reminder system. When a user becomes inactive for a certain period, the system sends a gentle reminder email to check on their well-being and encourage them to return.

The application is built using Flask (Python) for the backend and HTML, CSS for the frontend. User data and chatbot responses are stored using JSON, and bcrypt is used to ensure secure password storage. Email functionality is implemented using the Gmail SMTP server.

Overall, this project combines chatbot interaction, user authentication, music therapy, and email automation to create a simple yet effective mental health support system.
